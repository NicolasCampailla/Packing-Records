Initially, I set out to find the exact radical that expresses the side length for the classic configuration of 5 pentagons packed in a square. However, while trying to rebuild Viquerat's packing to calculate this, I noticed an interesting phenomenon: the configuration is not as obvious as it seems.
Specifically, the pentagon on the bottom left is not rigidly stuck in place! As you can see in my Desmos reconstruction, there is an unexpected degree of freedom. The purple pentagon has enough wiggle room to pivot or shift without breaking the boundaries of the square or overlapping the locked pentagons. I decided to stick it as close as possible to the square's edges.
This made me wonder about the technicalities of these configurations. Since this piece can move independently, does this shifted state technically count as a new packing? And if so, did I actually manage to steal one of the hundreds of Viquerat's records? This is up to you to decide, in any case the radical expression is now available!
